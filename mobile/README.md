Na primeira aula no SENAI, realizamos a configuração inicial do computador, começando pela criação e ajuste de um perfil de administrador (ADM). Em seguida, instalamos alguns programas essenciais para o desenvolvimento, como o Visual Studio Code (VS Code).

Também aprendemos a configurar e sincronizar o GitHub com o computador, utilizando comandos básicos do Git, como git config, para definir usuário, e-mail e permitir a integração correta com os repositórios. Essa etapa foi importante para preparar o ambiente de trabalho e facilitar o controle de versões dos projetos que serão desenvolvidos ao longo do curso.
