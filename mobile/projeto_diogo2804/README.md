# EcoApp - Controle de Hábitos Sustentáveis

## Introdução

Este projeto consiste no desenvolvimento de um aplicativo mobile utilizando Flutter, com o objetivo de incentivar práticas sustentáveis no dia a dia.

O aplicativo permite que o usuário registre hábitos ecológicos, acompanhe seu progresso e visualize seu impacto positivo no meio ambiente.

## Objetivo

* Desenvolver uma aplicação mobile responsiva
* Utilizar Flutter e Provider para gerenciamento de estado
* Aplicar conceitos de navegação e organização de interface
* Permitir acompanhamento de hábitos sustentáveis

## Tipo de Desenvolvimento

* Multiplataforma
* Framework: Flutter
* Linguagem: Dart
* IDE: Visual Studio Code ou Android Studio
* Plataforma: Android

## Funcionalidades

* Registro de hábitos sustentáveis
* Marcação de hábitos como concluídos
* Separação entre hábitos pendentes e concluídos
* Dashboard com resumo das ações
* Navegação entre telas
* Configurações do usuário

## Requisitos Funcionais

* O usuário pode visualizar hábitos pendentes
* O usuário pode marcar hábitos como concluídos
* O sistema atualiza automaticamente os dados
* O usuário pode navegar entre telas utilizando BottomNavigationBar

## Requisitos Não Funcionais

* Interface responsiva
* Navegação intuitiva
* Atualização em tempo real com Provider
* Código organizado em camadas

## Tecnologias Utilizadas

* Flutter SDK
* Dart
* Provider

## Gerenciamento de Estado

O aplicativo utiliza o Provider para:

* Controlar a navegação entre telas
* Armazenar hábitos pendentes e concluídos
* Atualizar automaticamente o dashboard
* Gerenciar ações do usuário

## Execução do Projeto

### Criação do Projeto

```bash
flutter create eco_app
```

### Instalação de Dependências

```bash
flutter pub get
```

### Execução

```bash
flutter run
```
